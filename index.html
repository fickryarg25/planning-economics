Base and decisions
  • Layout follows DESIGN.md at master 7084747a (23 Nov 2026); DESIGN.md not changed. CSS copied from the repo (Sneat core, theme-default, demo, aquaops-theme, Boxicons).
  • Data shape checked against staging 8ca8552c (23 Nov 2026). Staging is not a base branch; each page footer lists the feature branches it needs.
  • Money as IDR with font-monospace (IdrFormat), kg with two decimals, status badges bg-label-secondary / warning / success / danger.
  • Harvest: live biomass graded per line; Culled / Rejected deducted from commercial revenue; dead heads go to Mortality; flexible price per grade.
  • Planning: target margin 15% default; suggested price = break-even ÷ (1 − margin); kerapu standard marked Draft, lobster Unverified.
  • Feed Simulation: Field Team has no access; bags rounded up per feed; nursery feed brackets are sample values (BRD lists grow-out brackets only).
