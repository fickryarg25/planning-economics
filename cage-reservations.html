How the cage check works
  1. When a plan is saved as a baseline, each selected cage is reserved for its phase window (nursery: start to start + nursery DOC; grow-out: transfer to last size-class harvest).
  2. A cage can still be used later by a stocking or a grading transfer. This is allowed, with a warning (see Stocking Setup and Grading Transfer).
  3. 5 days before each reservation starts, the system checks the cage again. If it has an active stocking or another reservation in the window, an alert is sent to Alert Center for Ops Manager and Management.
  4. The plan shows a conflict badge until the cage is free, the plan is moved to another cage (Clone to v2), or the alert is resolved.
